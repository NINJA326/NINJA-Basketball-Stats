【NINJA AIRS Basketball Stats V22 初期設定】

1. Googleドライブで新しいGoogleスプレッドシートを作成します。
2. スプレッドシート上部の「拡張機能」→「Apps Script」を開きます。
3. 既存コードをすべて削除し、google_apps_script_code.jsの内容を貼り付けます。
4. 保存します。
5. 「デプロイ」→「新しいデプロイ」を選択します。
6. 種類は「ウェブアプリ」。
7. 実行するユーザーは「自分」。
8. アクセスできるユーザーは、運用に合わせて「全員」またはGoogleアカウント利用者を選択します。
9. デプロイして発行された /exec で終わるURLをコピーします。
10. GitHub Pagesでアプリを開き、「選手・同期設定」にURLを貼り付け「接続・同期」を押します。

【スプレッドシートに自動作成されるシート】
・設定
・選手名簿
・対戦相手
・試合一覧
・試合データ
・通算スタッツ
・各試合専用シート（日付_カテゴリー_vs_対戦相手）

【GitHub Pages】
このフォルダ内のファイルをすべてリポジトリ直下へアップロードし、Settings → Pages → Deploy from a branch → main / root を選択します。

【注意】
Apps Scriptを修正した場合は「デプロイを管理」から新しいバージョンとして再デプロイしてください。
端末のブラウザデータはオフライン時の一時保存に使います。同期後の正式データはスプレッドシートに残ります。
